# Learning-Based Point-Cloud Upsampling for Improved Semantic Segmentation

## Objective
Evaluate whether learned point-cloud upsampling improves semantic segmentation
of sparse 3D point clouds compared with direct segmentation and interpolation.

## Planned experimental comparisons
1. Dense point cloud -> semantic segmentation
2. Sparse point cloud -> semantic segmentation
3. Sparse point cloud -> interpolation -> semantic segmentation
4. Sparse point cloud -> learned upsampling -> semantic segmentation

## Dataset
S3DIS. The original archive and other large data artifacts are stored outside
Git, in Google Drive.

## Repository policy
Track source code, configurations, documentation, requirements, and lightweight
evaluation summaries. Do not commit datasets, checkpoints, or generated outputs.
